# REDCap API Guide

Practical guidance for securely accessing REDCap data through the API using R or SAS.

## Training website

➡️ **[Open the REDCap API Training](https://KWigg4.github.io/api_docs/)**

The training covers:

- Requesting REDCap API access
- Storing API credentials securely
- Retrieving REDCap reports with R or SAS
- Preserving unchanged source extracts
- Reusing extraction code with R functions and SAS macros
- Automating recurring REDCap data pulls
- Downloadable R and SAS example programs

## Code

Complete training programs are available in the [`Code`](Code/) directory.

The **Code & Downloads** section of the training website also provides options to view, copy, or download the individual programs.
